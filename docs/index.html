mod_zugang

Verschlüsselte WLAN- und Dock-Kennwortlisten als eigene Aktivität — Admins laden die Listen hoch, jede Schülerin und jeder Schüler sieht nur das eigene Kennwort per Klick. Installation über Site administration → Plugins → Install plugins.

Installation

  1. mod_zugang.zip oben herunterladen.
  2. In Moodle: Site administration → Plugins → Install plugins, Zip hochladen.
  3. Nach der Installation Listen anlegen unter Site administration → Plugins → Activity modules → Zugang → Listen verwalten.
